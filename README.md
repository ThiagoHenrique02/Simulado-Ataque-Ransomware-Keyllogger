# 🛡️ Simulação de Malware e Keylogger em Python

Projeto educacional desenvolvido em **Python** com o objetivo de estudar, em um ambiente controlado, conceitos relacionados ao funcionamento de **malwares **e** keyloggers**.

O projeto simula comportamentos encontrados em determinados tipos de ameaças digitais, permitindo compreender melhor como esses mecanismos podem funcionar e como podem ser identificados durante uma análise de segurança.

## 🎯 Objetivos

* Praticar programação em Python;
* Compreender conceitos básicos de malware;
* Estudar o funcionamento conceitual de keyloggers;
* Desenvolver conhecimentos relacionados à cibersegurança e análise de ameaças.

## ⚠️ Aviso

Este projeto possui **finalidade exclusivamente educacional** e deve ser executado somente em um **ambiente de testes controlado**, como uma máquina virtual.

A implementação deve evitar coleta, armazenamento ou transmissão de informações reais de terceiros. O objetivo é estudar os conceitos envolvidos e compreender como esse tipo de ameaça pode ser analisado e detectado.

## 🧰 Tecnologias

* Python 3
* Windows para ambiente de testes
* Máquina virtual para experimentação segura

## 📚 Contexto

Este projeto faz parte dos meus estudos de **Python e Cibersegurança**, utilizando programação para compreender conceitos de segurança ofensiva e defensiva.

> **Uso responsável:** utilize este projeto apenas em sistemas próprios ou em ambientes onde você tenha autorização explícita para realizar testes.
